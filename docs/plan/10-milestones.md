# 7. 开发规范

## 7.1 代码规范
- C++: 遵循 Unreal Engine 编码规范
- Rust: 遵循 Rust API Guidelines + clippy 规范
- 所有公共 API 必须添加文档注释

## 7.2 提交规范
- 使用语义化提交信息: `feat:`, `fix:`, `docs:`, `refactor:`
- 每个 Phase 完成后打 tag

## 7.3 测试规范
- 新功能必须附带测试
- 提交前运行 `cargo test` 和 `cargo clippy`
- 关键路径必须有集成测试覆盖
