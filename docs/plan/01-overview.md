# 1. 项目概述

> [← 返回导航](README.md) | [下一页: 架构设计 →](02-architecture.md)

## 1.1 目标

开发一个 **Unreal Engine MCP (Model Context Protocol)** 集成方案，让 AI 助手能够通过自然语言直接操作 Unreal Editor，实现场景编辑、蓝图操作、资产管理和编辑器控制等功能。

## 1.2 核心价值

- **AI 辅助关卡设计**: 自然语言驱动场景搭建
- **蓝图自动化**: AI 辅助蓝图节点创建、连接和变量管理
- **资产批量处理**: 自动化资产导入、导出和修改
- **编辑器控制**: 运行 PIE、保存关卡、执行控制台命令、模拟输入

## 1.3 当前能力 (50 工具)

| 类别 | 工具数 | 功能覆盖 |
| --- | --- | --- |
| Actor 操作 | 9 | 生成、销毁、复制、查找、属性、变换、Blueprint 生成 |
| 编辑器操作 | 10 | 状态查询、控制台命令、关卡管理、PIE 控制、选择 |
| 蓝图操作 | 8 | 创建、编译、信息查询、图形编辑、变量管理 |
| 资产操作 | 6 | 列表、信息、删除、重命名、导入、导出 |
| 材质操作 | 3 | 材质应用、实例创建、参数设置 |
| 组件 | 3 | 添加、移除、查询 |
| 网格/光照/特效 | 3 | StaticMesh、光源参数、粒子特效 |
| 输入/相机 | 2 | 按键模拟、视口相机查询 |
| 视口/调试 | 3 | 渲染模式、Debug 可视化、Actor 标签 |
| 关卡/代码 | 2 | 打开关卡、C++ 类生成 |
| 连接 | 1 | 连接状态检查 |

## 1.4 技术亮点

- **异步非阻塞**: Rust tokio 异步运行时 + Unreal FRunnable 独立线程
- **安全通信**: TCP localhost-only，不暴露到公网
- **类型安全**: Rust 编译期检查 + rmcp SDK 自动 JSON Schema 生成
- **可扩展**: 新增工具只需 3 步 (C++ handler → 注册 dispatch → Rust tool 定义)
