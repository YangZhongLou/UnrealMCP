# 1. 项目概述

> [← 返回导航](README.md) | [下一页: 架构设计 →](02-architecture.md)

## 1.1 目标

开发一个 **Unreal Engine MCP (Model Context Protocol)** 集成方案，让 AI 助手能够通过自然语言直接操作 Unreal Editor，实现场景编辑、蓝图操作、资产管理和编辑器控制等功能。

## 1.2 核心价值

- **AI 辅助关卡设计**：自然语言驱动场景搭建
- **蓝图自动化**：AI 辅助蓝图节点创建和连接
- **资产批量处理**：自动化资产导入、导出和修改
- **编辑器控制**：运行 PIE、保存关卡、执行控制台命令
