# 5. 风险与缓解

> [← 返回导航](README.md) | [← 上一页: 里程碑与规范](10-milestones.md)

| 风险 | 可能性 | 影响 | 缓解措施 | 当前状态 |
| --- | --- | --- | --- | --- |
| 多线程安全问题 | 高 | 高 | 所有 Editor API 调用必须在 Game Thread 上执行 | ✅ 已处理 (FRunnable + 主线程命令处理) |
| 大场景操作性能问题 | 中 | 中 | 添加超时机制，分批处理 | ⚠️ 未进行大规模测试 |
| 安全性问题 | 低 | 高 | 默认仅监听 localhost (127.0.0.1)，不暴露到公网 | ✅ 已处理 |
| 版本兼容性 | 中 | 中 | 明确支持 Unreal 5.x，条件编译 | ⚠️ 仅在 UE 5.3+ 测试过 |
| monolith 代码维护 | 高 | 中 | server.rs 1300+ 行，需模块化重构 | ⚠️ 部分重构代码废弃 (tools/ 目录) |
| TCP 通信超时/断连 | 中 | 中 | 每次请求按需连接，超时自动重连 | ✅ 已处理 |
| 测试覆盖不足 | 高 | 中 | 仅有基础集成测试 (3 个)，缺少单元测试和压力测试 | ⚠️ 需补全 |
| 文档滞后 | 中 | 低 | README 和里程碑文档已更新至当前状态 | ✅ 已处理 (2026/05) |
| 无日志推送 | 低 | 低 | UE 日志无法实时反馈给 AI，调试困难 | ✅ 已处理 (Phase 16: get_ue_logs) |
| MCP 协议变更 | 低 | 中 | 跟踪 rmcp SDK 更新，保持依赖版本可控 | ✅ 已处理 |
| BP 图形编辑复杂性 | 中 | 中 | UK2Node 体系庞大，目前仅覆盖常用节点类型 | ⚠️ 增量扩展 |
